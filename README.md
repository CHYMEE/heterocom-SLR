# Heterocom SLR

Systematic literature review on heterogeneous-compression federated learning and blockchain-based verification for industrial IoT.

## Project contents

- `paper/` — IEEE-style manuscript source, bibliography, and manuscript figures.
- `FINAL_FullText_Consensus_GapMatrix.xlsx` — consensus extraction matrix, full-text exclusions, and reconciled PRISMA summary.
- `docs/review-methods.md` — detailed screening, extraction, scoring, and methods audit trail.
- `docs/journal-targets.md` — candidate journals and closely related review exemplars.

## Method status

The locked selection flow is 4,437 records identified, 1,320 duplicates removed, 3,117 screened, 2,794 title/abstract exclusions after reconciliation, 323 full texts assessed, 30 full-text exclusions, and 293 included studies. See the methods audit trail for the Zotero, Rayyan, Excel, snowballing, and reviewer-agreement details, as well as reporting items to verify against original search records before submission.

## Build

The manuscript source is `paper/Hetero.tex`. Compile with an IEEEtran-compatible LaTeX toolchain from the `paper/` directory. Figures are included from `paper/figures/`.
